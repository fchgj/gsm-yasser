🇸🇦 العربية
1. أدخل رقم IMEI المكون من 15 رقمًا في الحقل المخصص.
2. اكتب رمز التحقق (Captcha) الظاهر بجانب الحقل.
3. اضغط على زر "فحص مجاني" للحصول على النتيجة.
4. للخدمات المدفوعة، تواصل معنا عبر واتساب.
🇬🇧 English
1. Enter the 15-digit IMEI number in the designated field.
2. Type the Captcha code shown next to the field.
3. Click the "Free Check" button to get the result.
4. For paid services, contact us via WhatsApp.
🇫🇷 Français
1. Entrez le numéro IMEI à 15 chiffres dans le champ prévu.
2. Tapez le code Captcha affiché à côté du champ.
3. Cliquez sur le bouton "Vérification gratuite".
4. Pour les services payants, contactez-nous via WhatsApp.
🇪🇸 Español
1. Ingrese el número IMEI de 15 dígitos en el campo designado.
2. Escriba el código Captcha que se muestra junto al campo.
3. Haga clic en el botón "Verificación gratuita".
4. Para servicios de pago, contáctenos por WhatsApp.
