1. البيانات التي يتم التعامل معها

تتعامل منصة GSMYasser Server مع البيانات الضرورية فقط لتشغيل أداة الاستعلام عن بيانات ومعلومات أجهزة iPhone عبر رقم IMEI:

  • رقم IMEI: يُستخدم لتنفيذ عملية الفحص وعرض معلومات الجهاز وتوليد التقرير.
  • بيانات التواصل: في حال اختار المستخدم التواصل معنا عبر قنوات التواصل المباشرة أو واتساب، فإن ما يشاركه يتم بناءً على مبادرته الشخصية.
  • بيانات تقنية محدودة: قد تُسجَّل مؤشرات تقنية أساسية (مثل توقيت الطلب أو تفضيلات المتصفح) لأغراض الأداء ومنع الإساءة.

2. عدم جمع بيانات مالية

لا يتضمن الموقع أي بوابات دفع إلكترونية ولا يطلب أو يخزّن أي بيانات بطاقات بنكية أو معلومات حسابات مالية.

3. مشاركة البيانات وتخزين المتصفح

  • قد يُرسل رقم IMEI إلى مزودي خدمة الفحص المعتمدين لجلب بيانات الجهاز المطلوبة، ولا يتم بيعه لأغراض إعلانية.
  • قد يستخدم المتصفح التخزين المحلي (LocalStorage) لحفظ تفضيلات العرض مثل اللغة أو المظهر.

1. طبيعة الخدمة ونطاقها

تُعد GSMYasser Server أداة مخصصة للاستعلام عن بيانات ومعلومات أجهزة iPhone عبر رقم IMEI فقط.

2. قواعد الاستخدام

  • يلتزم المستخدم باستخدام الأداة لأغراض مشروعة ومشروعة فقط، مثل التحقق من معلومات جهاز قبل الشراء أو المعاينة.
  • يُمنع استخدام أي أدوات آلية أو سكربتات لإغراق الموقع بالطلبات أو محاولة تعطيل الخدمة أو الالتفاف على آليات الحماية.
  • يتحمل المستخدم مسؤولية صحة رقم IMEI الذي يقوم بإدخاله.

تحتفظ المنصة بحق تطوير أو تعديل واجهات الأداة وخصائصها أو تحديث هذه الشروط في أي وقت بما يتوافق مع طبيعة تشغيل الخدمة.
